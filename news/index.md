# Changelog

## mstate2 0.2.0

The package has been simplified to the methods of Najera-Zuloaga, Besalú
and Gómez Melis (2025), so that their analysis of the DIVINE cohort can
be reproduced, plus subject-level bootstrap intervals.

- **Kept:**
  [`sojourn_to_panel()`](https://jcarmezim.github.io/mstate2/reference/sojourn_to_panel.md),
  [`rnd()`](https://jcarmezim.github.io/mstate2/reference/rnd.md),
  [`prep2()`](https://jcarmezim.github.io/mstate2/reference/prep2.md),
  [`P2est()`](https://jcarmezim.github.io/mstate2/reference/P2est.md),
  [`ckequations()`](https://jcarmezim.github.io/mstate2/reference/ckequations.md),
  [`compare2()`](https://jcarmezim.github.io/mstate2/reference/compare2.md),
  [`overlap_step()`](https://jcarmezim.github.io/mstate2/reference/overlap_step.md)
  (with the [`print()`](https://rdrr.io/r/base/print.html),
  [`summary()`](https://rdrr.io/r/base/summary.html) and
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html) methods) and
  [`simulate2()`](https://jcarmezim.github.io/mstate2/reference/simulate2.md).
- **New: bootstrap intervals.**
  [`P2boot()`](https://jcarmezim.github.io/mstate2/reference/P2boot.md)
  resamples whole patients and recomputes every estimate in each
  replicate (via per-subject count tables, so thousands of replicates
  are cheap).
  [`ckequations()`](https://jcarmezim.github.io/mstate2/reference/ckequations.md)
  and
  [`compare2()`](https://jcarmezim.github.io/mstate2/reference/compare2.md)
  then report percentile bootstrap intervals for the n-step predictions,
  which in a simulation study had close to nominal coverage, instead of
  the conservative evolution intervals.
- **Removed** (outside the scope of the paper): `markov_test()`,
  `P1est()`, `compare_order()`, `divergence()`, `divergence_table()`,
  `as_tmat()`, `probtrans2()`, `msprep2()`, `from_msdata()`, `P2reg()`
  and `P2reg_all()`.
  [`prep2()`](https://jcarmezim.github.io/mstate2/reference/prep2.md)
  loses the `covariates` argument, the `d` column of `triples` and the
  `pairs` component, and no longer accepts `msdata` objects.
- The conditional probability estimator (CPE) has been removed: the
  relative probability estimator (RPE) is more efficient
  (Najera-Zuloaga, Besalú and Gómez Melis, 2025) and is now the only
  estimator.
  [`P2est()`](https://jcarmezim.github.io/mstate2/reference/P2est.md)
  loses its `estimator` argument and the `t.hj` column of its estimate
  table.
- `P2est(ci = "logit")` gives intervals on the log-odds scale, which
  stay inside (0, 1) and behave better than Wald intervals for small
  probabilities (Brown, Cai and DasGupta, 2001).
- [`sojourn_to_panel()`](https://jcarmezim.github.io/mstate2/reference/sojourn_to_panel.md)
  warns when a positive sojourn rounds to 0 time units: the visit, and
  the transitions into and out of it, would otherwise be lost silently.
  (No visit is lost in DIVINE: all durations are whole or half days, and
  [`rnd()`](https://jcarmezim.github.io/mstate2/reference/rnd.md) rounds
  0.5 up to 1.)
- Both vignettes use the DIVINE cohort. Since the data are not
  distributed with the package, the vignettes are precomputed from
  `vignettes/*.Rmd.orig` with `vignettes/precompile.R`.
- Package infrastructure: João Carmezim is the new maintainer. The
  README has been rewritten around a worked example on the DIVINE
  cohort, the citation refers to the installed package version, and the
  package-level help page
  ([`?mstate2`](https://jcarmezim.github.io/mstate2/reference/mstate2-package.md))
  describes the workflow.
- New hex logo (dark version). The pkgdown website now uses the main
  vignette as its home page (`pkgdown/index.md`, generated by
  `vignettes/precompile.R`) instead of the README, and is built and
  deployed to GitHub Pages by a new `pkgdown.yaml` workflow.

## mstate2 0.1.0

- Initial CRAN submission:
  [`prep2()`](https://jcarmezim.github.io/mstate2/reference/prep2.md),
  [`P2est()`](https://jcarmezim.github.io/mstate2/reference/P2est.md)
  (RPE with variances and confidence intervals),
  [`ckequations()`](https://jcarmezim.github.io/mstate2/reference/ckequations.md),
  [`compare2()`](https://jcarmezim.github.io/mstate2/reference/compare2.md)/[`overlap_step()`](https://jcarmezim.github.io/mstate2/reference/overlap_step.md),
  [`simulate2()`](https://jcarmezim.github.io/mstate2/reference/simulate2.md),
  [`sojourn_to_panel()`](https://jcarmezim.github.io/mstate2/reference/sojourn_to_panel.md),
  `as_tmat()`, `from_msdata()`.
- `prep2(covariates = )` and `from_msdata(keep = )` carry baseline
  covariates through to a new individual-level `$triples` table.
- `markov_test()`: a formal, per-transition heterogeneity test of the
  first-order Markov assumption, built on
  [`P2est()`](https://jcarmezim.github.io/mstate2/reference/P2est.md)’s
  own asymptotics.
- `P2reg()`: a covariate-adjusted discrete-time cause-specific hazard
  regression (complementary log-log by default, the discrete-time
  analogue of Cox) for the 1-step second-order transition probabilities,
  with [`predict()`](https://rdrr.io/r/stats/predict.html),
  [`summary()`](https://rdrr.io/r/base/summary.html) and
  [`print()`](https://rdrr.io/r/base/print.html) methods.
- `compare_order()`/`divergence()`: compare a second-order prediction
  against a first-order
  [`mstate::probtrans()`](https://rdrr.io/pkg/mstate/man/probtrans.html)
  fit and quantify how many steps the difference persists.
- `tests/DIVINE_reproduction.R`: reproduces Table 2 and the Section 6.3
  evolution intervals of Najera-Zuloaga, Besalu and Gomez Melis (2025)
  from the real, published DIVINE cohort data (not bundled; the script
  skips quietly, with no network access, when the data file isn’t found
  locally).
- Every exported function now ships a runnable `@examples` block.
- Bug fix: `compare_order()` could silently reuse (flat-line) the last
  available row of `pt` when `nsteps` requested more steps than `pt`
  actually covered, instead of erroring; it now checks the full
  requested horizon against `pt`’s time range upfront.
- Bug fix:
  [`simulate2()`](https://jcarmezim.github.io/mstate2/reference/simulate2.md)
  no longer burns through the full `maxT` loop for individuals whose
  next state has zero probability under `tensor`/`first` (e.g. an
  underspecified row); their path now ends immediately instead of being
  retried every step until `maxT`.
- Test coverage raised from 90% to 98% by adding tests for previously
  untested error paths (unresolved states, malformed `pt`/tensor input,
  missing columns) and `print`/`summary`/`plot` methods.
- Bug fix: with staggered entry (`simulate2(entry = )`), an individual
  who entered at global step `s` was also advanced in that same step, so
  its entry state and first move were both recorded at time `s`. Newly
  entered individuals now make their first move at `s + 1`, giving one
  row per subject per time step.
- `print.markov_test()` no longer errors when printing a column subset
  of a `markov_test` object.
- The vignette has been rewritten as a complete, function-by-function
  guide: every exported function is explained (arguments, internal
  mechanics, output, interpretation, caveats) and run on a synthetic
  hospital cohort with known true parameters, so each step can be
  checked against the truth. It also shows how to apply the workflow to
  the DIVINE cohort.
- Bug fix: evolution-interval bounds from `ckequations(bounds = TRUE)`
  and
  [`compare2()`](https://jcarmezim.github.io/mstate2/reference/compare2.md)
  are now clipped to \[0, 1\]. The rows of the confidence-limit tensors
  do not sum to 1, so an upper bound feeding an absorbing state could
  exceed 1. First-overlap results
  ([`overlap_step()`](https://jcarmezim.github.io/mstate2/reference/overlap_step.md))
  are unaffected.
- New vignette
  [`vignette("reference")`](https://jcarmezim.github.io/mstate2/articles/reference.md):
  a complete reference with the definition, arguments, value, algorithm,
  errors/warnings and an example for every exported function, S3 method,
  object class and internal helper.
